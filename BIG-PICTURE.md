# Архитектурная карта проекта: Расписание СамГТУ (samgtu-schedule)

<!-- open-steps:begin -->
## О продукте
Автономное гибридное веб-приложение (PWA / Telegram Mini App / Android Capacitor) для студентов и старост Самарского государственного технического университета (СамГТУ). Обеспечивает мгновенный доступ к расписанию занятий в 4-недельном цикле с оффлайн-доступом, журнал посещаемости, трекер домашних заданий, систему защищенной синхронизации старост и автоматический мониторинг изменений расписания с официального сервера университета.

## Дорожная Карта и Очередь Задач (Бэклог)
### Фаза 1: Оптимизация, Эргономика и Безопасность (Must Have — текущий спринт)
- [x] Редизайн светлой темы: мягкий сланцевый фон `#eaeff5`, четкие рельефные белые карточки (`border-slate-300/80`, `shadow-[0_1px_3px_rgba(0,0,0,0.06),0_1px_2px_rgba(0,0,0,0.03)]`), насыщенные бейджи (`bg-*-100/90 text-*-900 border-*-300/80 font-bold`), соответствие стандарту контрастности WCAG AA (>4.5:1).
- [x] Полная адаптация безопасных зон (Safe Areas): поддержка TMA v7+ (`--tg-content-safe-area-inset-top`), системных шторок iOS/Android (`pt-safe`, `pb-safe`) во всех модальных окнах (`BugReportModal`, `EditLessonModal`, `SubjectTeachersModal`, `App.tsx`).
- [x] Тонкая настройка эргономики мобильных жестов: порог доминантности горизонтального свайпа в `SwipeableDays.tsx` повышен до `1.35x` для исключения паразитных переключений дней при вертикальной прокрутке.
- [x] Иерархический селектор групп (GroupSelector 2.0): фильтрация по институтам/факультетам, курсам, глобальный сквозной поиск по номеру группы от 2 символов и ручной ввод любой группы СамГТУ.
- [x] Надежное скачивание Word-отчетов старосты на Android/iOS в TMA: 4-уровневый каскад (Capacitor -> TMA /export-doc через Edge Worker с доставкой в ЛС Telegram-бота и нативным tg.downloadFile / системным браузером -> Web Share API -> HTML5 Blob), RFC 5987 UTF-8 стриминг, 100% приватность персональных данных.
- [x] Заглушка технических работ (Maintenance Mode): управляемый экран планового обслуживания с защищенным байпасом для админа.
- [x] Автоматический пентест и аудит безопасности (`tests/test_security_audit.ts`): проверка шлюзов Worker, санитизация от XSS, защита от брутфорса PIN и аудит бандла на утечки.
- [x] Защита от коллизий параллельной синхронизации: tombstone-изоляция удаленных заданий и предотвращение гонок в `utils/cloudSync.ts`.
- [x] Оптимизация бандла: динамическое разделение чанков с сохранением истории на GitHub Pages (входной бандл сократился с 942 кБ до 447 кБ raw / 97 кБ gzip; тяжелый `docx` и второстепенные модалки/вкладки изолированы в React.lazy и on-demand загрузку).
- [x] Очистка устаревших остаточных ссылок Firebase (`firebase.ts`, `firestore.rules`, `firebase-blueprint.json`, исключение пакетов `firebase` и `xlsx` из зависимостей).
- [ ] Быстрый чип-переключатель подгрупп (1 п/г / 2 п/г) в шапке расписания.
