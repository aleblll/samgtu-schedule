# Персональный Telegram Mini App (TMA) Планер дня

Высокопроизводительный мобильный планер для совмещения учебы в СамГТУ (группа 3-ИНГТ-101), репетиторской деятельности (МСК) и тренировок («Треня с Тёмиком» и гибкий «Зал»).

Выполнен в строгом дизайне **Anti-AI-Slop** (Linear / Things 3 / Raycast):
- Без неоновых радужных размытий и пустых мультяшных градиентов;
- Моноширинные таймкоды (`JetBrains Mono`);
- Высокая мобильная информационная плотность;
- Тёмная тема (матовый графит `#0F1115`) и светлая тема (фарфор `#F7F8FA`).

---

## Предустановленные данные (Seed Data)

1. **🎓 Университет (3-ИНГТ-101, СамГТУ):**
   - Двухнедельный цикл (чётная и нечётная недели);
   - Официальная сетка пар СамГТУ (1..7 пары);
   - Исключены чужие преподаватели и накладка на 31 августа.
2. **💼 Репетиторство (Индивидуальные уроки):**
   - Фиксация по часовому поясу **МСК** (с бейджем «МСК» и поддержкой местного самарского времени `UTC+4`);
   - Ученики: Макс, Нина, Ева, Честер, Карим, Арина, Андрюха;
   - Переключение статусов в один клик: `Ожидается` ➜ `Проведен` ➜ `Оплачен` / `Отменен`.
3. **🏋️ Тренировки:**
   - Вт, Чт: `20:30 – 22:00` «Треня с Тёмиком» (фиксированная);
   - Пн, Ср, Пт: «Зал» (плавающие слоты в окнах между парами и учениками).

## Возможности приложения

- **Единый вертикальный таймлайн:** Все три сферы выстраиваются в строгую хронологическую линию с маркером текущего времени «Сейчас».
- **Интеллектуальные окна:** Подсветка свободных пауз более 45 минут с возможностью в 1 клик поставить туда «Зал» или задачу.
- **Быстрый перенос (Quick Reschedule):** Пресеты `+1 час`, `+2 часа`, `-1 час`, `На вечер (19:00)` или выбор дня.
- **Автономность и сохранение:** Сохранение в `IndexedDB`, фоновая синхронизация с `Telegram.WebApp.CloudStorage`, экспорт/импорт в `.json`.
- **Интеграция с Telegram:** Тактильный отклик (`HapticFeedback`), нативные цвета заголовка, поддержка безопасных зон `safe-area-inset`.

## Запуск в разработке

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production
npm run build
```

## Подключение к Telegram Bot

1. В `@BotFather` создайте бота или выберите существующего.
2. Перейдите в `/newapp` или `Bot Settings` -> `Menu Button` -> `Configure menu button`.
3. Укажите URL развернутого приложения (или локальный туннель ngrok/Cloudflare/localtunnel при тестировании).
