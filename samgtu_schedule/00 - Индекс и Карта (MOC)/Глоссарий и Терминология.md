# 📖 Глоссарий и Терминология

Справочник терминов, сокращений и концепций, используемых в архитектуре и кодовой базе **samgtu-schedule**.

---

### 1. Академические термины СамГТУ
* **4-недельный цикл** — учебный цикл университета. Семестр состоит из повторяющихся 4-х недель: 1 и 3 недели считаются нечетными, 2 и 4 — четными. Некоторые предметы идут строго раз в 4 недели (например, лабораторные раз в месяц).
* **Блоки семестра (1-й и 2-й блок)** — деление семестра на две половины для промежуточной аттестации деканатом. Ведомости посещаемости закрываются отдельно по блоку 1 и блоку 2.
* **Сетка звонков (`CALL_SCHEDULE`)** — строгое расписание звонков на пары: 1 пара (08:00–09:35), 2 пара (09:50–11:25), 3 пара (11:40–13:15), 4 пара (13:30–15:05), 5 пара (15:20–16:55), 6 пара (17:10–18:45), 7 пара (19:00–20:35).
* **Шифр группы (Алиас)** — официальное наименование студенческой группы в СамГТУ: например, `3-ИНГТ-111` (Институт нефтегазовых технологий, 3 курс, 111 группа), `3-ФАИД-110` (Факультет автоматики и информационных технологий).

---

### 2. Платформенные и Технические Термины
* **TMA (Telegram Mini App)** — веб-приложение, запущенное внутри клиента Telegram (через `Telegram.WebApp` SDK). Имеет доступ к теме оформления пользователя, Haptic Feedback и безопасной среде без необходимости установки из Google Play / App Store.
* **PWA (Progressive Web App)** — веб-приложение, устанавливаемое на рабочий стол любого браузера и работающее без интернета благодаря Service Worker.
* **Capacitor** — открытый кроссплатформенный мост, компилирующий веб-код (HTML/JS/CSS) в полноценный нативный Android APK с прямым доступом к системным API.
* **Directional Lock (Блокировка направлений)** — UX-алгоритм в жестовых свайперах ([[SwipeableDays.tsx - Жестовый Свайпер]]), блокирующий вертикальную прокрутку страницы во время горизонтального перелистывания дней недели.
* **Offline First** — концепция архитектуры, при которой приложение всегда считывает данные из локального хранилища (`localStorage`), запускаясь за 0 мс без ожидания ответа сервера, а сетевые запросы выполняет асинхронно в фоне.

### 3. Бэкенд и Безопасность
* **Cloudflare Worker** — бессерверный (Serverless) скрипт на движке V8, работающий на граничных узлах (Edge Network) Cloudflare по всему миру с минимальным latency.
* **ExtendsClass JSON Bin** — облачное хранилище JSON-документов с постоянным доступом по уникальному ID бина (используется для хранения расписаний групп).
* **DTO (Data Transfer Object)** — стандартизированная структура данных, передаваемая между клиентом и облаком.
* **Whitelisting (Белый список полей)** — механизм защиты от уязвимости Mass Assignment, при котором сервер отбрасывает любые несанкционированные поля входящего JSON, пропуская только строго описанные.
* **Circuit Breaker (Автоматический выключатель)** — защитный шаблон проектирования, который прерывает процесс автосверки расписания при нестабильности API СамГТУ, защищая базу данных от затирания пустыми или битыми данными.
* **Ring Buffer (Кольцевой буфер)** — структура данных фиксированной емкости (150 записей в `logger.ts`), где новые записи вытесняют самые старые при заполнении, предотвращая утечки памяти.
* **Web Crypto API (SHA-256)** — нативный криптографический модуль браузера, позволяющий вычислять криптографические хэш-суммы паролей и PIN-кодов без тяжелых сторонних библиотек.
