# 🧪 Комплекс Автоматических Тестов Регрессии и Надежности

## 1. Зачем проекту автоматические тесты
Приложение обслуживает критическую повседневную задачу студентов СамГТУ. Любая ошибка в расписании (неправильно указанная аудитория, ложная отмена пары, неверно рассчитанные часы в ведомости) приводит к дезориентации сотен студентов.
В проекте реализован комплекс из **39 автоматических сьютов тестов** в директории `tests/`.

## 2. Структура тестовых наборов

| Категория тестов | Файлы тестов | Что проверяется |
|---|---|---|
| **Безопасность и Auth** | `test_auth_hashes.ts` | Валидация криптографических SHA-256 хэшей PIN-кодов старост и админа |
| **Санитизация и DTO** | `test_sanitization.ts` | Защита от Mass Assignment, Whitelisting полей, отсечение вредоносных пейлоадов |
| **Телеметрия и Логи** | `test_telemetry.ts`, `test_logger_diagnostics.ts` | Ring buffer на 150 логов, антифлуд-дедупликация ошибок (кулдаун 60 сек) |
| **Баг-репорты** | `test_bugreport_feature.ts` | Корректность сборки FormData, отправка логов и скриншотов через Worker |
| **Математика Расписания** | `test_attendance.ts`, `test_semester_cycles.ts`, `test_tz_boundaries.ts` | 4-недельный цикл, границы семестра, переход через часовые пояса (Самара UTC+4) |
| **Верификация Групп** | `test_ingt209_schedule.ts`, `test_faid_schedule.ts`, `test_htf215_verification.ts` | Соответствие сеток пар реальному расписанию кафедр СамГТУ |
| **UX и Жесты** | `test_swipe_gestures.ts`, `test_telegram_webapp.ts` | Directional Lock свайпера, корректная интеграция с Telegram SDK |

## 3. Как запустить тесты
Мастер-раннер запускает все сьюты параллельно:
```powershell
npx tsx tests/run_all.ts
```
Результат: **100% PASS** (0 failures).
