## 🔍 Анализ инцидента

В логе клиента зафиксированы две записи:
```json
{
  "level": "ERROR",
  "category": "SYSTEM",
  "message": "Script error.",
  "data": { "filename": "", "lineno": 0, "colno": 0 }
}
```

### Причина возникновения:
В мобильном клиенте Telegram Android в WebView внедряются нативные мосты (bridge scripts, `TelegramWebviewProxy`). Согласно спецификации HTML5 (Runtime script errors), любые ошибки сторонних скриптов без CORS маскируются браузером как `"Script error."` с пустым именем файла и нулевой строкой. 

### Принятые меры:
1. В `utils/logger.ts` добавлена фильтрация анонимных кросс-доменных ошибок (`isMutedScriptError`).
2. Ошибки сторонних инъекций теперь логируются с уровнем `WARN` вместо `ERROR` с пояснением: `External/Injected script event (muted by browser CORS policy)`.
3. Предотвращена ложная отправка алертов о крашах через `sendCrashReport` при срабатывании сторонних скриптов.
