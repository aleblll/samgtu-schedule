# 📜 ADR-006: Circuit Breaker в ночном парсере СамГТУ

## 1. Контекст и Проблема
Официальный API расписания СамГТУ (`samgtu.ru/api`) работает нестабильно:
* Во время технических работ или сбоев сервера он может возвращать HTTP 500, HTTP 502 Bad Gateway.
* Иногда сервер возвращает пустой массив пар (`[]`), хотя на самом деле семестр идет.
* Если наивный робот синхронизации запишет пустой ответ сервера в рабочую базу, все студенты на утро проснутся с пустым расписанием («пар нет»).

## 2. Принятое решение
В скрипте [[samgtuParser.ts и nightly_sync.ts - Парсер СамГТУ]] реализован защитный паттерн **Circuit Breaker** (Автоматический аварийный выключатель):
1. **Проверка статус-кода**: Если API СамГТУ отвечает статусом отличным от 200 OK, процесс мгновенно завершается.
2. **Проверка аномалий объема данных**: Если парсер получил менее 5 пар на всю учебную неделю для группы, это расценивается как сбой на стороне университета. Синхронизация блокируется.
3. **Проверка валидности структуры**: Каждая пара проверяется на наличие обязательных полей (название предмета, номер пары, день недели).
4. **Аварийный алерт**: При срабатывании Circuit Breaker база данных остается нетронутой, а разработчику в Telegram отправляется предупреждение: *"Синхронизация СамГТУ прервана: API вернул аномальные данные"*.

## 3. Последствия
* **Положительные**: Полная защита от разрушения рабочей базы расписания из-за багов на стороне университета.
* **Отрицательные**: Если расписание группы действительно сократилось до нуля пар (например, на время каникул), потребуется ручное подтверждение.
