# 📜 ADR-001: Cloudflare Worker и JSON Bins вместо выделенного VPS

## 1. Контекст и Проблема
Для работы приложения расписания требовался бэкенд, который решает три задачи:
1. Хранение оперативных изменений расписания каждой группы (отмены, переносы, домашние задания).
2. Проксирование телеметрии и баг-репортов со скриншотами в Telegram Bot API.
3. Сокрытие секретных ключей доступа.

Традиционный подход предполагал аренду выделенного Linux VPS сервера, установку Node.js, базы данных PostgreSQL / MongoDB, настройку Nginx, SSL-сертификатов (Certbot) и постоянный мониторинг аптайма.

## 2. Рассмотренные альтернативы
1. **Выделенный VPS (Ubuntu + Node.js/Fastify + PostgreSQL)**:
   - *Минусы*: Ежемесячная финансовая стоимость (от 5-10$ в месяц), необходимость постоянного администрирования, риск падения сервиса при неоплате или сбое сервера, задержка отклика (latency) до удаленного датацентра.
2. **Firebase Firestore / Realtime DB**:
   - *Минусы*: Жесткая привязка к Google Cloud, блокировки в некоторых сетях РФ, сложность настройки тонких правил безопасности без переплаты.
3. **Бессерверная связка: Cloudflare Worker + ExtendsClass JSON Bins (Выбранное решение)**:
   - *Плюсы*: 100% бесплатный тариф, граничная сеть Edge с временем отклика < 20 мс, отсутствие операционной системы, которую нужно обновлять или патчить, отказоустойчивость уровня Cloudflare.

## 3. Принятое решение
Принято решение отказаться от классического сервера в пользу бессерверной архитектуры:
* Вся маршрутизация, фильтрация, проверка прав и отправка телеметрии возложена на скрипт [[cloudflare-worker.js - Пограничный Шлюз]].
* Хранение изолированных данных каждой группы возложено на облачные JSON-корзины **ExtendsClass**.

## 4. Последствия
* **Положительные**: Нулевые затраты на содержание инфраструктуры. Мгновенный холодный старт (0 мс в Edge V8). Высокая защищенность от DDoS.
* **Отрицательные / Риски**: Лимит бесплатных запросов Cloudflare (100 000 запросов в день), чего с запасом хватает на десятки тысяч студентов СамГТУ благодаря локальному кэшированию на клиентах.
