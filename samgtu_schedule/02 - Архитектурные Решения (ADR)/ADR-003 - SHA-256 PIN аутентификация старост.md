# 📜 ADR-003: Легковесная SHA-256 PIN аутентификация старост

## 1. Контекст и Проблема
Для предоставления старостам прав на отмену пар и редактирование расписания требовался механизм авторизации. 
Классическая регистрация (логин, email, пароль, подтверждение по ссылке, JWT-токены, OAuth) создавала огромный барьер входа: старосты не хотят тратить время на регистрацию в очередном сервисе.

## 2. Принятое решение
Использовать легковесную ролевую модель на базе коротких PIN-кодов с криптографическим хэшированием **SHA-256** через нативный браузерный **Web Crypto API**:
1. Староста вводит PIN-код группы в модальном окне редактирования.
2. Клиент хэширует введенную строку по алгоритму SHA-256.
3. Полученный 64-символьный hex-хэш сверяется с доверенным хэшем группы, хранящимся в коде.
4. Открытый PIN нигде не сохраняется и не передается в сеть.

```typescript
async function verifyPin(pin: string, targetHash: string): Promise<boolean> {
  const msgUint8 = new TextEncoder().encode(pin);
  const hashBuffer = await crypto.subtle.digest('SHA-256', msgUint8);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
  return hashHex === targetHash;
}
```

## 3. Последствия
* **Положительные**: Нулевое трение для старосты (ввел 4-6 цифр и сразу редактируешь). Полная независимость от серверов авторизации.
* **Отрицательные**: Если PIN-код станет известен постороннему студенту группы, тот сможет отменить пару. Решение: смена PIN-кода администратором через обновление хэша.
