# 🔎 samgtuParser.ts и nightly_sync.ts: Парсер СамГТУ

## 1. samgtuParser.ts (Парсер API расписания)
* Формирует запросы к официальному REST API СамГТУ.
* Преобразует сырые университетские JSON-объекты в типизированные структуры `Lesson` и `DaySchedule`.
* Корректно определяет подгруппы, типы занятий (лек/пр/лаб), парсит ФИО преподавателей и номера аудиторий.

## 2. nightly_sync.ts (Ночной робот автосверки)
* Запускается ежедневно по крону GitHub Actions.
* Последовательно проверяет все зарегистрированные группы.
* Сравнивает официальные данные с текущим файлом [[constants.ts и types.ts - Реестр и Типизация]].
* Включает **Circuit Breaker** (прерывание при аномалиях API).
* Формирует наглядный дифф и отправляет отчет в Telegram.
