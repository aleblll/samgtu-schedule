# 📝 AttendanceTracker.tsx: Журнал Посещаемости

## 1. За что отвечает
Полнофункциональный электронный журнал посещаемости для старосты:
* Список студентов группы.
* Матрица отметок присутствия по дням и парам: «Был» (пусто/галочка), «Пропуск по уважительной причине» (У), «Пропуск по неуважительной причине» (Н).
* Автоматический расчет суммарных пропущенных академических часов:
  - За текущую неделю.
  - За 1-й блок семестра.
  - За 2-й блок семестра.
  - За весь семестр суммарно.

## 2. Экспорт в официальный формат Word
В интерфейсе встроена кнопка «Экспорт ведомости в Word». При нажатии вызывается модуль [[exportWord.ts - Генерация Ведомостей Word]], который на лету генерирует файл `.docx` с титульными данными СамГТУ, таблицей пропусков и полями для подписи старосты и замдекана.
