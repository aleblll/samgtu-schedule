# ✏️ Поток 2: Внесение Правок Старостой и Синхронизация

## Диаграмма Потока Данных

```mermaid
sequenceDiagram
    autonumber
    actor Starosta as Староста группы
    participant UI as EditLessonModal.tsx
    participant Auth as auth.ts (Web Crypto)
    participant Store as App.tsx (State)
    participant LS as LocalStorage
    participant CF as Cloudflare Worker (Sanitizer)
    participant DB as ExtendsClass JSON Bin
    actor Students as Одногруппники

    Starosta->>UI: Клик по занятию -> Переключатель "Отменить пару"
    UI->>Auth: Проверка роли (starosta/admin)
    
    alt Роль еще не подтверждена
        Auth-->>UI: Запрос PIN-кода группы
        Starosta->>UI: Ввод PIN-кода
        UI->>Auth: crypto.subtle.digest('SHA-256', PIN)
        Auth-->>UI: Хэш совпал -> Установка роли 'starosta'
    end
    
    Starosta->>UI: Нажатие кнопки "Сохранить"
    UI->>Store: Обновление состояния customSchedule
    Store->>LS: Запись в локальный кэш
    Store-->>Starosta: Карточка моментально стала зачеркнутой (Оптимистичный UI)
    
    Note over Store,DB: Фоновая отправка в облако
    Store->>CF: PUT /sync/:binId (Тело с изменениями)
    CF->>CF: Whitelisting DTO Sanitizer (удаление посторонних полей)
    CF->>DB: Запись очищенного JSON
    DB-->>CF: 200 OK
    CF-->>Store: Подтверждение записи
    
    Note over DB,Students: Доставка одногруппникам
    Students->>CF: Фоновый опрос / открытие приложения
    CF->>DB: Чтение корзины группы
    DB-->>Students: Возврат расписания с отмененной парой
```

## Ключевые принципы надежности
* **Оптимистичный интерфейс**: Староста не ждет ответа облака. Карточка меняется сразу.
* **Фильтрация DTO**: Cloudflare Worker гарантирует, что в базу попадает только валидный объект расписания.
